# Icon options

Rendered by `swift design/icon-options/render.swift`. Pick one and the app icon set is regenerated from it with `sips` (see the git history of `App/WindowShepherd/Assets.xcassets/AppIcon.appiconset`).

- **option-a.png**: the ⧉ mark the menu bar already uses, on a deep-blue tile. Simple and recognisable at 16 px.
- **option-b.png**: a shepherd's crook gathering two app windows, on a dusk-sky tile. Tells the name's story. *Used as the placeholder for now.*
- **option-c.png**: a white crook hooking the ⧉ mark, on a green "pasture" tile. Blends both.
- **menubar-crook.png**: a possible menu-bar glyph (template image: black on clear; macOS tints it). The app still shows ⧉ in the menu bar, as the Hammerspoon version did.
