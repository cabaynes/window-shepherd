# App Spots Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Window memory that survives app relaunches and restarts: each app's windows go back to that app's remembered spots for the current screen setup, and every move is checked for where it actually landed.

**Architecture:** A new pure-state `AppSpotBook` (beside `LayoutBook`) holds, per setup key and bundle ID, a list of spots, plus a runtime map of which window holds which spot. A new `AppSpotStore` persists it to `app-spots.json` and seeds it once from today's layouts. `Shepherd` feeds it confirmed placements (its own moves, restores, the undocked default, the user's moves outside a guessing period), asks it for free spots when a window it doesn't recognise appears or a screen change finds windows with no per-window entry, and checks each move's landing at the next settled tick.

**Tech Stack:** Swift 6, SwiftPM (`swift test`, XCTest), AppKit + Accessibility (live side only), XcodeGen app in `App/`.

**Spec:** `docs/superpowers/specs/2026-11-03-app-spots-design.md`

## Global Constraints

- **Nothing may hang or slow the Mac.** The 2 s tick and snapshots use only the CoreGraphics list and cheap `NSRunningApplication` lookups. Accessibility calls run only on an `AXWorker`, with the 0.5 s timeout, never on the main thread.
- **Never re-send a position.** `applyFrame` is unchanged. A window that didn't land is never retried automatically.
- **Public repo.** No personal window titles or file names in code, tests, comments or docs. Tests use made-up app names ("Safari", "Notes" are fine as app names).
- **Shortcuts** are written ⌃ ⌥ ⌘ key ⇧.
- **Nothing the user reads is faint or disabled grey.**
- **Precedence**, for any window: its own per-window entry → its app's free spot → the "Windows opened while undocked" default (only at a change that adds a screen) → leave it.
- **Main windows only** (`AXStandardWindow` subrole) take or create spots.
- **Forget unused spots after 30 days** (`forgetAfter`). A held spot never expires.
- Match the surrounding code: short `///` doc comments, terse inline comments that say *why*, existing naming (`book`, `store`, `key` for the setup key).

## Review Focus

1. **A window the app reopens and the user drags away within 2 s.** Expected: left where the user put it, and its spot replaced. Test: `testDraggedBeforeSecondSightingIsLeftAndBecomesASpot` (Task 6).
2. **Two apps' windows sharing one screen setup, spots never cross apps.** Expected: a new Notes window never takes a Safari spot. Test: `testSpotsNeverCrossApps` (Task 2).
3. **The same window seen in two screen setups.** Expected: it can hold one spot per setup; leaving and returning to a setup doesn't free or duplicate its spot. Test: `testHoldersArePerSetup` (Task 2).
4. **A fixed-size or minimum-size window moved by a hotkey.** Expected: not reported as missed, no alert, no flashing. Test: `testImposedSizeIsNotAMiss` (Task 8).
5. **Damaged or missing `app-spots.json`.** Expected: start from a fresh seed, logged, never crash, and never re-seed over a good file. Test: `testDamagedFileReseedsAndLogs` (Task 3).

### Task 2: `AppSpotBook`, the pure state

**Files:**
- Create: `Sources/WindowShepherdCore/Restore/AppSpots.swift`
- Test: `Tests/WindowShepherdCoreTests/AppSpotBookTests.swift`

**Interfaces:**
- Produces:
```swift
public struct AppSpot: Codable, Equatable {
    public var id: String          // UUID string, stable for the spot's life
    public var scr: String
    public var unit: UnitRect
    public var used: Double        // last time a window was put in it or sat in it
    var spot: Spot { Spot(scr: scr, unit: unit) }
}

/// setup key → bundle ID → spots.
public typealias AppSpotMap = [String: [String: [AppSpot]]]

@MainActor
public final class AppSpotBook {
    public var spots: AppSpotMap
    /// Runtime only (not saved): setup key → window id → the spot id it holds.
    public var holders: [String: [String: String]] = [:]
    public static let maxPerApp = 20
    public init(spots: AppSpotMap)

    /// A confirmed placement (yours or Window Shepherd's). If the window holds a
    /// spot for this setup and app, that spot moves here; otherwise a new spot is
    /// added and held. Over `maxPerApp`, the least recently used unheld spot goes.
    public func record(key: String, bundle: String, window: String, at spot: Spot, now: Double)
    /// Refresh `used` for every held spot whose holder is in `visible`.
    public func touch(key: String, visible: Set<String>, now: Double)
    /// Drop holders whose window no longer exists (any setup); their spots stay, free.
    public func release(existing: Set<UInt32>)
    /// Drop unheld spots unused for `forgetAfter`.
    public func forgetOld(now: Double)
    /// Free spots for windows this book doesn't place yet: takes the N most
    /// recently used free spots, then pairs each window with the nearest of
    /// them to where it is (`at`), and marks them held. Returns window id → spot.
    public func assign(key: String, bundle: String, windows: [(id: String, at: Spot?)], now: Double) -> [String: AppSpot]
    /// True if the window holds a spot in this setup.
    public func holds(key: String, window: String) -> Bool
}
```
- Nearness: distance between unit-rect centres when on the same screen. A spot on another screen than `at` (or `at == nil`) counts as distance 10. Pair greedily, closest pair first. Ties keep recency order.

### Task 8: Checking where a move landed

**Files:**
- Create: `Sources/WindowShepherdCore/Engine/Landing.swift`
- Modify: `Sources/WindowShepherdCore/Engine/Shepherd.swift` (`apply`: snaps and bulk moves), `Shepherd+Restore.swift` (restore and `.place` actions, settled tick), `Shepherd+Revert.swift`
- Test: `Tests/WindowShepherdCoreTests/LandingTests.swift`

**Interfaces:**
- Produces:
```swift
/// What each move asked for, filled from worker threads (locked), checked on main.
final class Landing: @unchecked Sendable {
    struct Expect { let pid: pid_t; let id: UInt32; let wanted: CGRect; let resizable: Bool; let at: Double; let retry: Retry }
    enum Retry { case move(Placer, String), restore }   // the placer and label for a move
    func expect(_ e: Expect)
    /// Expectations older than `after` seconds, removed and returned.
    func due(now: Double, after: Double) -> [Expect]
}
```
  - Every move action, after `setFrame` succeeds, calls `landing.expect(...)` with `win.isResizable`, read on the worker in the same action.
  - Each settled tick: `checkLandings(visible:, screens:)` takes `due(now:, after: 1.5)`. A due window that's no longer visible is dropped.
  - A **miss** is either:
    - its CG origin is off by more than 4 pt in x or y from `wanted`; or
    - it is resizable and its width or height came out more than 4 pt *smaller* than asked.
  - On a miss:
    - log `"<App> window <id> didn't land: asked x,y w×h, ended at x,y w×h"`;
    - `book.leftBehind.insert`, and `book.protect[id] = ` the current spot;
    - remove it from `restoredIds` when `.restore`;
    - `spots`: if the miss came from an app-spot or Window Shepherd move, undo that move's `record` (re-`record` the window's previous spot, which `recordSpot` keeps for 1 tick as `lastRecorded[id]`);
    - group misses by `Retry` into one `offerRetry`: `.move` → `apply(Selection(byPid:, retry: true), placer:, label:)`, `.restore` → `restore()`;
    - `setFlashing(true)` if not already.
  - Never call `setFrame` again from here.
